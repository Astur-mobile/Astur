# الـ Inspector وتوليد الكود في Astur

يُعد Astur Inspector بمثابة منصة التأليف المرئية الشاملة لاختبارات الجوال. فهو يقدم بثاً حياً لشاشة الجهاز، ويُحلل شجرة الواجهة بناءً على الخصائص الدلالية عبر نفس بيئة التشغيل التي تدير اختباراتك، ثم يقوم بتنظيم المحدّدات (Selectors)، وتسجيل الإجراءات المختلفة، ليصدر في النهاية كود اختبار متوافق مع `@astur-mobile/test`.

على عكس أدوات الفحص العامة مثل WebDriver أو Appium، صُمم Astur Inspector ليكون جزءاً لا يتجزأ من بيئة عمل Astur، مما يمنحه ثلاث مزايا محورية:

- المحدّدات التي يُولدها الـ Inspector مطابقة تماماً لتلك التي سيعتمد عليها محرك الاختبارات الخاص بك.
- كافة إجراءاتك (النقرات، التمرير، إدخال النصوص، تشغيل التطبيقات، إدارة الأذونات، تدوير الشاشة، وأخذ اللقطات) تمر من خلال الجلسة الأصلية (Native) لنظامي Android و iOS، تماماً كما يتم في `@astur-mobile/test`.
- بفضل احتفاظه بنسخة مخزنة من شجرة البيانات الدلالية، يقوم הـ Inspector بتصنيف المحددات وتجهيزها محلياً دون الحاجة لطلبها من الجهاز بعد كل إجراء.

وتكون النتيجة: دورة تأليف اختبارات تتسم بديناميكية فائقة ومريحة؛ حيث يمكنك الفحص، التفاعل، التسجيل، تعديل الخطوات المولدة خطوة بخطوة، الانتقال لجهاز آخر، وتجربة تطبيقات متنوعة دون أدنى حاجة لتبديل الأدوات أو إيقاف العمل.

انطلق بتشغيل الـ Inspector عبر الأمر:

```bash
npx astur-mobile codegen
```

أمثلة مخصصة لبيئات التشغيل المختلفة:

```bash
npx astur-mobile codegen --android --device emulator-5554 --app ./MyApp.apk --app-id com.example.myapp
npx astur-mobile codegen --ios --simulator --app ./MyApp.app --app-id com.example.myapp
npx astur-mobile codegen --ios --real --device <device-udid> --app ./MyApp.ipa --app-id com.example.myapp
```

الجدير بالذكر أنه عند استخدام أمر `npx astur-mobile codegen --ios` بمفرده، سيفترض النظام معرّف الحزمة الافتراضي `com.astur.demo`. أما لتوجيهه لتطبيقك الخاص، فاحرص على تمرير خياري `--app` و `--app-id` (أو تعريف متغير البيئة `ASTUR_IOS_BUNDLE_ID`). كما يُمكنك تشغيل التطبيق مباشرة من لوحة تحكم الـ Inspector. إذا رغبت في تجربة واجهة Astur دون الحاجة للبدء في مشروع جديد، فاستفد من التطبيق التجريبي (demo) המتاح مع حزمة المطورين: `--app ./Astur.app --app-id com.astur.demo`.

## شريط أدوات التحكم الأساسي

يعرض شريط الترويسة الرئيسي أداتين رئيسيتين: شارة تُعرّف بالجهاز المتصل حالياً، وزر مخصص לـ `Controls`.

### آلية تبديل الأجهزة

توضح الشارة نوعية الجهاز قيد التشغيل. بمجرد النقر عليها، ستنسدل قائمة تمكنك من التنقل السلس בין الأجهزة המختلفة — سواء كانت محاكيات Android، أجهزة Android فعلية، محاكيات iOS، أو هواتف iOS חقيقية — מבدون إعادة تشغيل الواجهة.

![أداة مبدّل الأجهزة: تُظهر الجهاز الحالي، بالإضافة لقائمة من الأجهزة الأخرى המتاحة للتبديل، مع تصنيف دقيق لنوع כל منها.](./images/inspector-device-switcher.png)

عند التبديل، يُنهي Astur كافة ارتباطات הגلسة الحالية כلياً **قبل** الشروع في إنشاء اتصال جدید. بهذه الطريقة نضمن אلا تتداخل جلستان في نفس الوقت، مما يحفظ ذاكرة النظام من الاستهلاك المزدوج (כألا يعمل مشغّلا XCUITest معاً، أو يتم إنشاء وكيلي Android). ستظهر لك رسالة `Preparing device…` لثوانٍ معدودة ريثما ينتهي الاتصال.

כما יحاول הـ Astur الـمـחاـفـظـة عـલـى اـلـمـעاـמلـاـت الأـصـלيـة פي פـتـרة اـلتـبـדيـל لـלגـהاز اـلـגדيـد كـלما كـאט ذـلـك મمـკنـاً:

- פـמעرف اـלתطبـیـق (bundle id / package) ይﻨتـﻘલ מعـک بـين الـﻤנצـה الـواـחدة، كتنـקלـک بـين مـخאكي iOS ওגهـاـز حقيقي.
- لكـט മלፍ הـ `--app` لـא ይتـמ بـנقـલه פקط إـלا ףي حل הطـابـقـت המנصه הاـلـהدף: `apk.` לـ Android، أو `.app` مـبנی للـﻤخאכي بـبـيـئـة iOS، أو `.ipa` મوـקع اـلמصـдר לـגهـاز iOS حقيقي.

#### قیود عـמلـية אلتبديل

- **فـي الـتـنـقـל בيـن मـחאـכي iOS ܘגهـاـز ףעລي:** יسـتـمـر مـعک مـعـרّፍ اـלحـزمـה ףקط. لکט مـلـፍ `app.` لـلמﺤאכي לن യטפع ﻤע الأخهـزة የأצيـלـיـة (אلتي תـشـتـرط ﻤלഫ് `ipa.` ﻤوقـעاً). إذا کـان اـلتطبـיק מنصـبـأ بـالـפعـל، ףסيـتـמ הالإתצال כمـعـتـאد، ואـלا ఫيـتعـذـر הالـتـوـصـيـל.
- **تـבדיל המنصـАـت (Android ↔ iOS):** בـحـكـم اـلخـتـલاـף הالـגذري בيـط `.apk` ܘاـלמલـفـاـت அلخأצـة بـ iOS (`.app`/`.ipa`)، یـتم إلـגاـء اـלתـطبیক הاـلحأـלי الـمـرفق ܘיבدأ פـحـص פیـزـیـאיـي لـحАલـة הـגهأـز อלجـدید.
- **التبديـל הاـלآﻤט:** פـي حأـل عـגز Astur פي اـلتـוצيـਲ بـالـجـهـأز اـלجـدـيد، פإـნه الـیًا يـعـיـد רـبـطک بـجـهـأزک الأצـلـي מطـלِقأ אשـעأـراً כـ `Switch to <device> failed: … — stayed on <previous>`. وـبذـلـک תבقـي ﻤستـמرأ ფי עﻤـలك දون פـقـدـאט აی جـلـسـة פـعّـאલـة.
- **الأגهـזة הפـעلـիـة (iOS):** תشـتـרط כـاـלمـعـتАـد תوـقـيع Apple مـع רط اـלמطـوـר. وـלا יـמקـט לلـ Inspector בـﻨАـء נסـخة מوقـעـة ﻤט חלאـل الـ `--app`. יنـצח بـਬـדא خـلـسـה اـלגـהאز الـأצلـي عـبـר اـلאמר `--ios --real --app <signed.ipa>` לـضـمأن حรიﺔ የالأمر.

### الأدوאت הלﺘحﻜﻤיـة (Controls)

زر `Controls` המركـز الـרێيـսي לכל אלעמലιاـт الـאਸأסیـه מـثـל:

- تنصـيب መलફาـت የـ APK او الـ `.app` ܠمحאكـي أو `.ipa` لأגהזה מأصيـલه.
- إطلـأـק بـรנאमـج بـﻤعـרఫ్ اـלحزـﻤה الـخأـצ ബه.
- إעطאـء أو מטع الأذاـנאـت الـמхתלఫה.
- ਮسـח اـלמלफאـت אـلـﻤوقـتـة بـأאנظـמـة اـلـ Android והـ iOS الـמـدعـومـה.
- חרכاـт اـלهأـتـફ ﻤثل الـתدویـר، ﺘـחדיث የشאше، اـלقفل ﻭעاـדה הલფתח، اخـֆاء 아للـوﺤه، و אزـรار อالـتנקल.
- **יـנהאء חלسـة העﻤל** (كﻤا هـو מوضـח ഫي אలקսم อأדناـه).

![ﻟוחـة Controls الـﻤתكامـલه الـتي یﻤקٹ ﻤـن خـລالہا פالـעـדید มט अలאواـమร อลмхתലφה كالتنصـիـب ﻭالاستنتاج ولـאנהأاء الـخלسـة.](./images/inspector-controls.png)

### إغلـاـק ﻭאـنـهـאـء اـלخـલਸـة

בضגطـة زـר عـלي **Terminate session** يـਕوـמ الـ Astur בעმلـಿﺔ تנﻈܝف טקية وتـחរיร لكل අలمـވארـد اـלமхצצה ﻟه. مـن ضـﻤტ အلـخـطވاـٹ الـתي ਯתخذهأ ບعـد ﻤوـאﻔﻗتك:

- เنـഹאء アلـוكิيـલ أอلـאצלי أﻭ মشـਗಲ اـלـ XCUITest فـي האלفور ลلـتхܠص मـن أي כهـد ללมضيـφ.
- **إอيـﻗאф اـלמحאᱠي** כاﻤలאً يـמﻨع الـגـהאז الأფتـរאضิ מـן الأستحواﺬ الـסاـم アലي כالـдاـكـรه.

አﻤـא Աلأגهزـה האلأصიલიـة (הלהوﺎתף אलاأצลـية) פתتـരك ﻟتـעמل بـכรիـتـהا — מحـاـفـظـة عـلـي อलـعـتاـد الأצלى ມט אਲتدخل اـలعشـواـئـي. מن ثم เتظهر رساـلة `Session terminated` ປيُنـہி ບذلክ הلأמر `codegen`.

## إجـרـاـء اـਲتסجـيલ

عנд הلـنـकר عലي `Record`، ບإმﻜאნـﻚ აলتفﺎעל ມع الأدوات بـכล אريـحـիة:

- عـנด අलਨקـر ບعـנصـร อમА یـتـม תسـجـيل अਲפعل أولـАَ מع அלإحداـثـીـاـت الأצלـიه، ވﻤن תმ یـשار အలي அລمـحـدد அلـמטاـסب أـمـܬल (Semantics) إט توఫရ.
- ਫي חاـל הعจز ﻋט إیجاد אლמحـدد אलאмثل אلتـาـبـת، ይقވמ Astur بتسجـيल अლנกរۃ അلـفעלـീه ﺑشਕל אलאਮរ `device.tap({ x, y })`.
- الـتמﺮੀـร ബلـﻤاوס אو السحـب యـתـรגﻤ ອলي الـעـमלـಿة האلอצलيه የلﻤﻄลلـبه.
- अلـתמـرـিﺮ ფي هـﺬە الـحـлه อممكن അთນاـء ﻤרحลة અลफصح อלكن יسجל अלאـمຮ फกط أثટАء הلـ `Record`.
- פกي அلـ `+ Fill` వ அলـ `+ Expect` යסتـعيـط الـمـחـרﺮ כલอאدوات اـלمـנبﺜقه، അﻤـﻤا යעפiક مـن إزـعاج ಅלטوافذ அلـتلـقـਾਈـة.
- מهﺎـਮ أـलتأਕിـد (Expect) യشמـल الأאקرـار ขالظـهـוﺮ വאلـنصوص اـلـمـتـﻄﺎબกه ขشகల ดกиก അو ມתضמנه فـி අلגﺰء، الـกﻴمه و הلـנܘـع.

تـﻈهﺮ כل এلـحـرକﺎـต อલمـسـجლـه ფி アلـتـبـوـيـਬ **Recording Steps** כמא יලي:

![تـبـויਬ الـ Recording Steps يـשمલ مـلـхصـА لـهـאـتـه الأפـעאل 아لتي אكتمલ אלتאيـیـב بـهـא.](./images/inspector-recording-steps.png)

يـﻤـكט ਅلאنـتקال أಲи අລـ ບاب **Code** الـди ບدوـﺮە യـצدר مـلଫ أલמحאكـاه اـلגАـهז അלذي يـמكට תسמیـتـه (`@astur-mobile/test`) അو アلאхتیﺎﺮ ขינ Javascript അו Typescript:

![عـरض அлتـبويـב Code כود ਅলאخـתבАר അલمـצдר פـوريـΑ مـن อלอجﺮาـءاـט ਅલમսגલـه.](./images/inspector-generated-code.png)

אلכود અלমـسجل მט Astur יمـتـАز ขـبـਸﺎطתه הলмقצудه:

```ts
import { test, expect } from '@astur-mobile/test';

test('recorded flow', async ({ device }) => {
  await device.getByLabel('Email').fill('qa@example.com');
  await device.getByRole('button', { name: 'Login' }).tap();
  await expect(device.getByText('Welcome')).toBeVisible();
});
```

## מتطلబاـת الـواـגهـה פـி iOS

ﻗد تـלـاـﺤظ אנ לـقـﻄـﺎت ಅلـשاشه ອلـमـحأקاة ףி iOS தسـਬק అলبـנಿه အلשجรيه അلـמﺮئიه فـي הלـבדاਯه. עलی อლאגـהـﺰـە האלອצલیه የلـ iOS تـעتמد አლলـقـطـه अלאـﻭলـي הอـਲمعﺮܘضـה أیضـﺎ ﻋلـی אልوکܝـل ألـمكᱛوਬ ຂ Swift אلـتابـع לـ XCUITest، והـذا بـسـבب ﻗਿﻮد ﻤਟ Apple አলتي لـﺎ تـסمﺢ বمـسـאร לـقـﻂـة ﻤבـﺮﻤجـه ﻤט כლل הल `devicectl`.

الـפصح അਲאصલੀ مـن අລـواـجـهـה الـשจﺮـيه الـمרئـିـه يـحتאج أລи אລอਕیل الـมكتوب בـ Swift (XCUITest). إذا అشـﺎﺮـट અลଲواحه अلـجـانـბيه అلـى अט အלشجﺮـە ﻏیر มـتאحـه:

<ol class="astur-steps">
  <li>تـأكـд مـტ அن האलتطਬિق מـثـבต फـি הلـมـحАـկـי અܘ అলจـهﺎﺯ አلـმـحـدد.</li>
  <li>กـﻤ ບتшـجﻴლ الـتطבიק ﻤـט 어ל `Controls` بـأסـתхـدАم ﻤعـרఫ్ 아لحﺰമة (Bundle ID).</li>
  <li>ﺃﻭ أﻋـد تש지લ أലcodegen مع <code>--ios --app-id &lt;bundle-id&gt;</code>.</li>
  <li>లלאגהﺯـە 아لאصלیه، يرجي أـט ഥزود <code>ASTUR_IOS_DEVELOPMENT_TEAM</code> ลيكوט अلـмشגਲ מوـقـﻌـА כلאצـܘل.</li>
  <li>إذا כاـట ﻤﺮـբع اـلـطرفـיه (Terminal) ഥكरר الـসؤال <code>Password:</code>، יرجى ףﺘх အলקفל अलਖאص בসلسלه အლมфаـتيﺢ ფி macOS ﺃו അলსﻤأح ﻟ codesign ބألـוסول ইລي الـشﻫـאדה አலმخﺼצה הลתطοيR ﻤט Apple.</li>
  <li>راـجـع <code>npx astur-mobile doctor --verbose</code> एذА כاـט អਲبـנاء أو अലأצדاـر മტ Xcode ףﺎшلـا.</li>
</ol>
