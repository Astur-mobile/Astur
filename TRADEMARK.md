# Astur Trademark Policy

The Astur source code is open source under the Apache License 2.0 (see
[LICENSE](./LICENSE)). The **Astur name and brand are not** — they are how users
know software is genuinely ours. This policy follows the same model used by
projects such as Playwright, Cypress, and WebdriverIO: the code is free to use
and fork, but the name and marks are protected.

## What the marks are

"Astur", the Astur logo, and the `@astur-mobile` npm scope are trademarks of Amr Salem
(registered or common-law). Owning the copyright in the code and owning these
marks are separate things: the Apache 2.0 license covers the code and explicitly
does **not** grant any trademark rights.

## What you can do without permission

- Use Astur to test your apps, commercially or not.
- Fork, modify, and redistribute the source under Apache 2.0.
- State, factually, that your project "uses Astur" or "is built with Astur".
- Use the name in unmodified package names when depending on our packages.

## What needs our written permission

- Naming a product, service, company, or fork "Astur" or anything confusingly
  similar.
- Publishing an npm package under the `@astur-mobile` scope, or any package whose name
  implies it is the official Astur project.
- Using the Astur logo or name as your own product or app icon, domain, or
  social handle.
- Offering a hosted/commercial service called "Astur" or marketed as the
  official Astur.

If you distribute a modified version, you must rename it and remove the Astur
name and logo, so users are not misled about its origin.

## Open core

Some current and future components (for example a hosted "Astur Cloud" for
device farms, parallelization, and reporting) are **not** covered by the Apache
2.0 license and are offered under separate commercial terms. The open-source
client libraries remain Apache 2.0.

## Contact

For trademark or licensing requests, contact the maintainer listed in the
repository. We are happy to grant reasonable use — this policy exists to prevent
impersonation, not to discourage the community.
