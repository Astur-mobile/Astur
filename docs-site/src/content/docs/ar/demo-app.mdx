**تطبيق Astur التجريبي** (`com.astur.demo`) هو تطبيق أصلي صغير ومبسط، هدفه الوحيد هو توفير بيئة أتمتة مستقرة يمكن التنبؤ بها. تم تصميم كل شاشة لتعرض وظيفة محددة — كالنقر، التمرير، التمرير الأفقي، السحب، ملء النماذج، رفع الملفات، وعروض WebView الهجينة — باستخدام معرفات اختبار ثابتة لضمان موثوقية عمل المحددات عبر مختلف المنصات وعمليات التشغيل.

إنه التطبيق ذاته الذي تعتمد عليه أمثلتنا القابلة للتشغيل؛ حيث يقابل كل لقطة شاشة أدناه ملف اختبار مخصص في مشروع القالب الجاهز [astur-boilerplate](https://github.com/Astur-mobile/astur-boilerplate) (وضمن مجلد [`examples/`](https://github.com/Astur-mobile/astur-boilerplate) في هذا المستودع).

## كيفية الحصول عليه

يتوفر التطبيق التجريبي ضمن القالب المبدئي وفي مجلد `assets/` الخاص بهذا المستودع:

- **أندرويد (Android):** `assets/astur.demo.android.apk`
- **أندرويد باستخدام (Flutter):** `assets/astur.demo.android_flutter.apk`
- **محاكي iOS:** `assets/astur.demo.ios.simulator.zip` (استخرج الملف ليظهر `assets/Astur.app`)
- **محاكي iOS باستخدام (Flutter):** `assets/astur.demo.ios.simulator_flutter.zip` (استخرج الملف ليظهر `assets/Runner.app`)
- **جهاز iOS حقيقي:** `assets/astur.demo.ios.ipa`

## بيئات التشغيل المستهدفة

تعمل نفس نصوص الاختبار على البيئات الأربع المختلفة. يقوم Astur بتثبيت التطبيق التجريبي ووكيله تلقائياً عند التشغيل لأول مرة؛ وكل ما تحتاجه هو جهاز متاح للتشغيل.

| نوع الجهاز | طريقة التعرف | المتطلبات |
| --- | --- | --- |
| **محاكي Android** | عبر `adb devices` (مثل `emulator-5554`) | جهاز افتراضي قيد التشغيل فقط. يتكفل Astur بتثبيت التطبيق (APK) والوكيل. |
| **جهاز Android حقيقي** | عبر `adb devices` | تفعيل خاصية "تصحيح أخطاء USB" والسماح للجهاز بالاتصال. عملية التثبيت تلقائية كما في المحاكي. |
| **محاكي iOS** | عبر `xcrun simctl list devices booted` | محاكي قيد التشغيل مع توفر ملف التطبيق `Astur.app` مفكوك الضغط. |
| **جهاز iOS حقيقي** | عبر `xcrun devicectl list devices` | جهاز موثوق تم تفعيل "وضع المطور" فيه، وملف `.ipa`، مع ضبط `ASTUR_IOS_DEVELOPMENT_TEAM` لتوقيع وكيل XCUITest. |

جرب أداة Inspector مباشرة دون كتابة سطر كود واحد:

```bash
# محاكي Android
npx astur-mobile codegen --android --device emulator-5554 \
  --app ./assets/astur.demo.android.apk --app-id com.astur.demo

# محاكي iOS
npx astur-mobile codegen --ios --simulator \
  --app ./assets/Astur.app --app-id com.astur.demo
```

أو قم بتشغيل كافة الاختبارات من مشروع القالب الجاهز [astur-boilerplate](https://github.com/Astur-mobile/astur-boilerplate):

```bash
npx astur-mobile test --config config/android/playwright.config.ts
```

:::note[التحكم في الـ DOM ضمن WebView]
تدير الدالة `device.webContext()` تفاعلات الـ DOM داخل الـ WebView **لكل من Android وiOS (سواء على أجهزة حقيقية أو محاكيات)**.

- **على Android** — يقوم التطبيق بتفعيل التصحيح عبر `WebView.setWebContentsDebuggingEnabled(true)`، مما يفتح منفذاً لبروتوكول Chrome DevTools. يتم توفير التطبيق بهذه الإعدادات مُسبقاً.
- **على iOS** — يستخدم التطبيق الخاصية `WKWebView.isInspectable = true` (لإصدار iOS 16.4 فأعلى)، ويشترط وجود الأداة `ios-webkit-debug-proxy` (إصدار 1.9 فأعلى) مثبّتة عبر `brew install ios-webkit-debug-proxy`. ويقوم Astur بربط Web Inspector تلقائياً في المحاكي.

مع ملاحظة أن التجهيزة `webview()` (المشابهة لـ `web.page` في Playwright) مدعومة في Android فقط، بينما في iOS يمكنك الاعتماد على `device.webContext()` أو استخدام المحددات الأصلية المباشرة.
:::
