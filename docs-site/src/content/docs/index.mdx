<section class="quantum-why-section">
  <div class="why-accent-line"></div>
  <div class="why-content">
    <div class="section-badge">THE PHILOSOPHY</div>
    <h2 class="section-headline">Why Astur?</h2>
    <p>
      Astur is named after the <strong>astrolabe</strong>: a portable, historic astronomical instrument that compressed complex calculations and sky observations into something small enough to hold.
    </p>
    <p>
      Astur brings that same philosophy to handheld-device automation: a compact, high-performance test API backed by a lightning-fast native runtime that handles device lifecycle, network orchestration, and screenshot-diagnostics under the hood.
    </p>
  </div>
</section>
