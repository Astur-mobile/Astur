## Why Astur

Astur is named after the astrolabe: a portable instrument that compressed complex observation and calculation into something small enough to hold. Astur brings that same idea to handheld-device automation: a compact test API backed by a fast native runtime.

```ts
import { expect, test } from '@astur/test';

test('login', async ({ device }) => {
  await device.getByLabel('Email').fill('qa@example.com');
  await device.getByLabel('Password').fill('secret');
  await device.getByRole('button', { name: 'Login' }).tap();

  await expect(device.getByText('Welcome')).toBeVisible();
});
```

Start with [Getting Started](/getting-started/) or open [Inspector And Codegen](/inspector/) if you want to generate your first test from a running device.
