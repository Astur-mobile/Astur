# astur-mobile

The [Astur](https://github.com/Astur-mobile/Astur) command-line tool — device-native mobile automation for Android and iOS with Playwright ergonomics and no Appium server.

```bash
npm install -D astur-mobile @astur-mobile/test @playwright/test
```

```bash
npx astur-mobile doctor      # check your environment
npx astur-mobile devices     # list emulators / simulators / devices
npx astur-mobile init        # scaffold a config
npx astur-mobile codegen     # record a test from a live device (alias: inspect)
npx astur-mobile test        # run your Astur/Playwright specs
```

You can also run tests from the **VS Code Playwright extension** play button — Astur inherits the full Playwright Test runner.
