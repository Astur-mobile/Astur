# @astur-mobile/protocol

Internal runtime package of [Astur](https://github.com/Astur-mobile/Astur). Shared selectors, command/snapshot types, and capabilities.

Most users should install **[`@astur-mobile/test`](https://www.npmjs.com/package/@astur-mobile/test)** and **[`astur-mobile`](https://www.npmjs.com/package/astur-mobile)** instead of depending on this package directly.
