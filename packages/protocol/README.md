# @astur-mobile/protocol

Part of [Astur](https://github.com/Astur-mobile/Astur), Playwright-style test automation for real
Android and iOS apps on native agents, with no Appium server. Shared selectors, command and snapshot types, and capabilities.

You don't need to install this package yourself. Install the test integration and the CLI, which
bring it in:

```bash
npm install -D @astur-mobile/test astur-mobile @playwright/test
```

Full documentation: **[astur-mobile.github.io/Astur](https://astur-mobile.github.io/Astur/)**.
