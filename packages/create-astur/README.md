# create-astur

Scaffold a mobile test project with [Astur](https://github.com/Astur-mobile/Astur): Playwright-style
tests for real Android and iOS apps, on native agents, with no Appium server.

```bash
npm create astur@latest my-mobile-tests
cd my-mobile-tests
npx astur-mobile doctor
npx astur-mobile test
```

It asks what you target (Android, iOS, or both; emulator, simulator or real device) and writes a
working Playwright Test config and a first test.

Full documentation: **[astur-mobile.github.io/Astur](https://astur-mobile.github.io/Astur/)**.
