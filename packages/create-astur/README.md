# create-astur

Project scaffolder for [Astur](https://github.com/Astur-mobile/Astur) — device-native mobile automation for Android and iOS.

```bash
npm create astur@latest my-mobile-tests
cd my-mobile-tests
npx astur-mobile doctor
```

Generates a ready-to-run Astur + Playwright Test project.
